# Hosting without a local computer

The existing Express + WebSocket server can run as a Render **Web Service**.
Use the repository root, not `server/`, as the deployment root: the server also
needs `client/` and the root `weights.bin`.

## Prepare the repository

The complete integrated source, `weights.bin`, `tools/check-deployment.cjs`,
and `render.yaml` must be included in the GitHub branch you deploy. Local
untracked files are not available to Render. No Git commit or push is performed
by these deployment files. Keep credentials out of the repository.

Run `node tools/check-deployment.cjs` to check deployment assets. The build uses
the existing binary; it does not install PyTorch or regenerate weights.

## Deploy

1. Sign into https://dashboard.render.com and connect your GitHub account.
2. Choose **New > Blueprint**, select the updated repository/branch, and review
   the service from `render.yaml`. It explicitly selects the Free plan.
3. Deploy and wait for the service to become live. Render supplies its HTTPS URL.
4. Open that URL with `/?role=host` on Phone 1. Scan its QR from Phone 2.
5. Wait for readiness, then repeat the two-phone inference test.

Alternatively, choose **New > Web Service** and enter:

| Setting | Value |
| --- | --- |
| Runtime | Node |
| Root directory | Leave blank |
| Build command | `node tools/check-deployment.cjs && npm ci --prefix server --omit=dev` |
| Start command | `node server/server.js` |
| Instance | Free |
| Environment | `NODE_VERSION=24`, `NODE_ENV=production` |
| Auto-deploy | Off |

The server already reads Render's `PORT` environment variable. The browser
automatically uses the hosted origin for assets and `wss://.../signal`, so no
hardcoded localhost URL needs replacing. Use one server instance because lobby
state is stored in process memory. A server restart loses existing lobbies;
established P2P inference can continue independently.

After deployment, the local Node/ngrok processes and your computer are no longer
needed. Both phones should remain on the same Wi-Fi for the intended local P2P
test. HTTPS hosting does not remove the need for a direct WebRTC connection.

## Hosting versus inference

Render serves browser code and the weight file and relays connection-setup
messages. It does not run transformer layers or relay inference activations,
generated bytes, or session controls. Those stay on the P2P mesh after setup.

Free Render services sleep after 15 minutes without inbound traffic; a cold
start can take about a minute. Open the site ahead of a demonstration. Each
uncached phone downloads approximately 44 MB, which counts toward hosting
bandwidth limits. Review current account limits before a public demo.
